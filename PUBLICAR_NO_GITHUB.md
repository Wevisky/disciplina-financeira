# Publicar gratuitamente no GitHub Pages

1. Entre em github.com e crie um repositório público, por exemplo `disciplina-financeira`.
2. Clique em **Add file > Upload files**.
3. Envie **os arquivos que estão dentro desta pasta** (index.html, app.js, styles.css, manifest etc.). Não envie a pasta como uma subpasta única.
4. Confirme em **Commit changes**.
5. Abra **Settings > Pages**.
6. Em **Build and deployment**, escolha **Deploy from a branch**.
7. Selecione a branch `main`, pasta `/ (root)` e clique em **Save**.
8. Aguarde alguns minutos. O GitHub mostrará o endereço HTTPS.
9. Abra esse endereço no Safari do iPhone.
10. Toque em **Compartilhar > Adicionar à Tela de Início**.

## Atualizações
Substitua os arquivos no mesmo repositório. O aplicativo verificará a nova versão quando for aberto com internet.

## Dados
Os gastos ficam no armazenamento local do navegador/aplicativo e não são enviados ao GitHub. Antes de trocar de endereço, navegador ou aparelho, exporte o backup.
